## Функциональность MVP Call центра

### Основные рассматриваемые требования и методы их реализации

Для развития функциональности работы с депозитными ставками в Call центре Банка выделяем новые компоненты внутри сервера приложений, разработка выполняется сотрудниками Банка:
- Обработка Заявок на депозит с Сайта
- Обработка Депозитных ставок из АБС

Компоненты Frontend'a для реализации требований дорабатывает подрядчик.

Также для реализации требований работы внешнего КЦ, реализуем интеграцию с ним по приему депозитных ставок из АБС через ETL шину, добавляя нового потребителя для Депозитных ставок. Технология реализации, согласно условию - файловое взаимодействие.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
Альтернатив по расположению новых функций КЦ нет, можно рассмотреть выполнение всех работ подрядчиком, однако это решение не очень правильно с точки зрения развития компетенций у внутренней команды Банка в Java-стеке (см. ADR01) 

**Недостатки, ограничения, риски**

Из рисков и недостатков в точке проектирования видны риски перегрузки команды АБС
